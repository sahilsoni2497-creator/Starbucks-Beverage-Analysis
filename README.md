# ☕ Starbucks Beverage Analysis – Power BI Dashboard

An interactive Power BI dashboard created to analyze Starbucks beverage data and explore insights related to calories, caffeine, sugar, protein, and beverage categories.

The dashboard converts raw beverage data into interactive visualizations and KPI insights for easy analysis and understanding.

## 📊 Dashboard Overview

The dashboard provides an overview of Starbucks beverages using KPI cards, interactive charts, category analysis, and filters.

### Key KPIs

- Total Beverages
- Average Sugar
- Average Calories
- Average Caffeine

## 📈 Dashboard Features

- Average Calories by Beverage Category
- Beverage Category Distribution
- Average Caffeine by Category
- Top 5 Highest Caffeine Beverages
- Beverage Category Comparison
- Interactive Protein Range Filter
- Beverage Preparation Filter
- Dynamic KPI Cards
- Interactive cross-filtering

## 🛠️ Tools & Technologies

- Power BI Desktop
- Power Query
- DAX
- Data Cleaning
- Data Modeling
- Data Visualization
- Exploratory Data Analysis

## 🔍 Key Insights

The dashboard helps analyze:

- Beverage categories with higher average calories
- High-caffeine beverages
- Caffeine differences across categories
- Beverage distribution by category
- Sugar and calorie patterns
- Nutritional differences between beverages

## 🎛️ Interactive Filters

### Protein Range

Users can select a minimum and maximum protein value using the interactive range slicer.

### Beverage Preparation

Users can filter the dashboard based on different beverage preparation methods.

The dashboard visuals and KPI cards update dynamically based on the selected filters.

## 🎯 Project Objective

The objective of this project is to demonstrate practical skills in data cleaning, data analysis, DAX, dashboard development, KPI creation, and business-focused data visualization using Power BI.
